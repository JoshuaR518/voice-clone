# Mic comparison script

Read this **the same way every time** — same pace, same distance, same energy.
Roughly 45 seconds. Content is identical across takes so the only variable is the mic.

Before each take: same room, same time of day if you can, Mic Mode set to **Standard**.

---

Hey, this is Josh, and I'm testing how this microphone sounds.

I'm going to say a few things that push on different parts of speech. Peter picked
a pack of pickled peppers — that's for the hard consonants, the pops and plosives
that make a microphone distort if it's too close.

She sells seashells by the seashore. That one's for the sibilance, the sharp S
sounds that cheap capsules turn harsh and hissy.

Now I'll just talk normally for a moment, the way I'd actually tell a story, because
that's what this voice is going to be used for. Not announcements, not narration
exactly — just me, explaining something to someone, at the pace I'd really use.

And now I'm going to stop talking for five full seconds so we can hear the room.

[SILENCE — count to five]

Okay. That's the take.
